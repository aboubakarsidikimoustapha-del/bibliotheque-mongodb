# TP3 – Catalogue de la bibliothèque (Flask + MongoDB Atlas + Vercel)

1. `python -m venv .venv` puis activer l'environnement
2. `pip install -r requirements.txt`
3. Copier `.env.example` en `.env` et renseigner `MONGODB_URI`
4. `python app.py` puis ouvrir http://127.0.0.1:5000
5. Compléter les TODO dans `app.py` (voir l'énoncé du TP)
